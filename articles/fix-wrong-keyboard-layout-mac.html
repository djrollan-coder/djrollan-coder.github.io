Typed “ghbdtn” instead of “привет”? Fixing wrong-layout text on a Mac

By Roman MotornyiNovember 20, 20262 min read

If you type in two alphabets, you know the moment: you look up from the keyboard and see “ghbdtn” where “привет” should be. The text is not lost — every letter is just in the wrong layout. Here is why it happens and how to fix it without retyping.

Why it happens

The Russian ЙЦУКЕН layout and the English QWERTY layout share the same physical keys. When the wrong input source is active, each key still produces a letter — just from the other alphabet. So “привет” becomes “ghbdtn”, and “hello” typed in Russian comes out as “руддщ”.

Because the mapping is one key to one key, the text can be converted back exactly. Even the punctuation keys follow the rule: ; is ж, ' is э, [ is х, ] is ъ, , is б and . is ю.

Fix it without retyping

Lingrab adds a command to the macOS Services menu that converts selected text to the other layout, right where you typed it:

  1. Select the wrong text — “ghbdtn”.
  2. Right-click it, or open the app menu, and choose Services.
  3. Pick the Lingrab command. The word turns into “привет” in place.

Because it is a system service, it works in most apps that let you edit text: Notes, Mail, Pages, browsers, messengers.

Make it one keystroke. Open System Settings → Keyboard → Keyboard Shortcuts → Services, find the Lingrab command under Text and assign it a shortcut. Then you just select and press it.

Make it happen less often

  • Use a quick switch. In System Settings → Keyboard → Keyboard Shortcuts → Input Sources you can set the shortcut for “Select the previous input source”, usually ⌃Space. On Mac keyboards with a Globe key you can also set the Globe key to change the input source.
  • Keep the input menu visible. In System Settings → Keyboard → Input Sources, turn on “Show Input menu in menu bar”, so the current layout is always in sight.
  • Let each document remember its language. Turn on “Automatically switch to a document's input source” in the same place: a Russian chat stays Russian and an English email stays English.

Questions

Does it fix only Russian and English?

The classic case is QWERTY ↔ ЙЦУКЕН, which is what Lingrab's command is built for.

Is it free?

Yes. The layout fix is part of the free version of Lingrab, together with copying text from the screen and the clipboard history.
