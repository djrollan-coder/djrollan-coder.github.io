Two panels. Total control.

A fast dual-pane file manager for Mac in the spirit of Total Commander — with F-keys, tabs, a built-in terminal, an audio player and powerful file tools.

Coming soon Write to me to get notified about the release

macOS 13+ · Apple Silicon & Intel

Features

🗂️

Classic two panels

Keyboard-first file management with F3–F8, tabs, favorites bar, type-ahead search and a clickable path bar.

⚡

Fast file operations

Copy and move with speed, progress and a transfer queue, undo with ⌘Z, and a warning before the disk fills up.

💻

Built-in terminal

A real terminal next to your files: drop files to paste their paths, widen it over the second panel.

🎵

Audio & video player

Play tracks with a single click, build playlists, see bitrate, length and album art.

🧰

Power tools

Batch rename with live preview, duplicate finder, zip archives, image conversion and network share connections.

🎨

Make it yours

Skins, per-element colors, fonts, list modes and CPU and memory meters. Interface in English, Spanish and Russian.
